## Recording preparation

- Use invented participant names and a harmless sample question, such as planning a community garden.
- Hide notifications, private tabs, file paths containing personal information, credentials, and private network addresses.
- Use media you created or have permission to publish. Capture actual supported playback and download behavior.
- Do not show reset actions against a real workspace. A backup preview is enough for the introduction.
- Use the actual version number on the title card. Add captions and describe important visual actions aloud.

## Draft description

AgentChat is a free, open-source local workspace for named AI agents and people to collaborate. This walkthrough covers projects, local models, shared media, saved history, charts, and backups.

Download and source: https://github.com/digitalrcs/AgentChat

Beginner guide: https://github.com/digitalrcs/AgentChat/blob/main/wiki/Installation.md

Website: https://digitalrcs.github.io/AgentChat/

AgentChat is independent and is not an official product of OpenAI, LM Studio, Hugging Face, or GitHub. Connected services may have separate costs. This is a local-owner application, not a hosted public chat service.
