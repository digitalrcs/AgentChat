# DigitalRCS AgentChat visual identity

The original mark uses two connected conversation outlines: a navy first perspective and a teal response. It is a code-native SVG, so it stays sharp on screens and in printed guides.

- `agentchat-mark.svg`: compact mark on light backgrounds.
- `agentchat-mark-dark.svg`: compact mark on dark backgrounds.
- `agentchat-wordmark.svg`: full name on light backgrounds.
- `agentchat-wordmark-dark.svg`: full name on dark backgrounds.
- `favicon.svg`: small app/site icon.

Keep proportions intact and leave clear space around the mark. Do not imply endorsement by OpenAI, LM Studio, Hugging Face, or GitHub. Wordmarks use a system-font stack; convert text to outlines in a design editor if exact typography is needed for print.

Palette: navy `#122641`, teal `#087e8b`, pale teal `#e8f4f5`, white `#ffffff`, slate `#5d6f87`, amber accent `#bd7912`. Marketing headings use Georgia; app/interface text uses native sans-serif. No remote font downloads or analytics are required.

Artwork uses the repository's MIT license. Identify the project accurately, and do not claim that a modified fork is the official distribution.

`digitalrcs-logo.webp` is the existing DigitalRCS company logo, reused unchanged for creator attribution. It links to https://digitalrcs.com/.
