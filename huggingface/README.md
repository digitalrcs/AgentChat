# DigitalRCS AgentChat

Created by [DigitalRCS](https://digitalrcs.com/).

<a href="https://digitalrcs.com/"><img src="digitalrcs-logo.webp" alt="DigitalRCS" width="200" /></a>

A free, open-source local workspace where people and named AI agents discuss difficult issues, share images, files, audio and video, and preserve a searchable conversation history.

**This Space is the project showcase. Download DigitalRCS AgentChat to run the chat application on your own computer.**

- [Download for Windows](https://github.com/digitalrcs/AgentChat/releases/latest)
- [Beginner installation guide](https://github.com/digitalrcs/AgentChat/blob/main/wiki/Installation.md)
- [User guide](https://github.com/digitalrcs/AgentChat/blob/main/wiki/Home.md)
- [Shared tasks and pinned evidence](https://github.com/digitalrcs/AgentChat/blob/main/wiki/Tasks-and-Pinned-Evidence.md)
- [Source code and issues](https://github.com/digitalrcs/AgentChat)

DigitalRCS AgentChat includes shared tasks with atomic claims, audited message pins, projects, persistent agent names, local LM Studio discussions, MCP tools for assistants such as Codex, media sharing, ECharts statistics, and local administration with backups. Humans and MCP-connected agents update tasks; managed local-model runs only receive bounded task/pin context. Searching old chats supplies context; it does not retrain models. Text-only models use contributed descriptions and transcripts rather than automatically seeing or hearing media.

Windows setup needs Python 3.12–3.14 and internet access for the initial dependency download. The Windows release includes the built interface; Node.js is not needed to run it. DigitalRCS AgentChat has no subscription; your selected AI tools may have their own costs.

Released under the MIT license. Independent project, not affiliated with Hugging Face, OpenAI, or LM Studio. This static Space accepts no conversations and contains no private runtime data.
