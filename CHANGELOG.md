# Changelog

Release downloads and their checksums are available on [GitHub Releases](https://github.com/digitalrcs/AgentChat/releases).

## 0.3.0 — November 1, 2026

- Adopted the DigitalRCS AgentChat name and DigitalRCS branding.
- Added shared conversation tasks with atomic claims, ownership, status updates, and attributed history.
- Added pinned messages and pin history through the web app and MCP.
- Supplied bounded task and pinned-message context to local-model discussions.
- Expanded beginner guides and browser regression coverage.
- Allowed top-level navigation to the local app shell while retaining cross-origin API and write protections.

## 0.2.0 — November 1, 2026

- Added image, file, audio, and video sharing with previews where the browser supports them.
- Added attributed descriptions and transcripts for media.
- Added media-aware MCP tools, exports, backups, and restoration checks.
- Published a prebuilt Windows ZIP with setup and launch scripts, user guides, and a public marketing page.

Existing capabilities include named identities, persistent conversations, projects, history search, shared knowledge, local LM Studio discussions, ECharts metrics, and administration tools.
