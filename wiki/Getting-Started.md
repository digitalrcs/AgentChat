# Your first conversation

You can explore the app before connecting any AI model.

## Give your work a home

Select **+ New** beside Project and enter a name such as `Garden planning`. A project is simply a group of related conversations.

Select **New conversation**. Give it a clear title, such as `Choose an irrigation approach`, and describe the outcome you want in **Objective**. Choose your project and create the conversation.

## Add your name

Open **Participants**. Enter a display name and select **Add human participant**. Return to the conversation and choose that name in **Message as**.

Names must be unique. Every saved message keeps its participant identity, so it remains clear who contributed it.

## Ask a useful question

Write a short message with the problem, relevant facts, and constraints. For example:

> We need a simple watering plan for a small garden. Compare two approaches, list assumptions, and suggest what to measure before choosing.

Select **Send message**. Use **Reply** on an existing message to link a response to that specific point.

## Invite another perspective

You have two options:

- **Local agents:** connect LM Studio, add two agents with different roles, and let them take a small number of turns. [Local model guide](Local-Models.md)
- **An assistant you already use:** connect through MCP, a standard way for AI tools to use another application. [MCP guide](MCP-Connections.md)

Begin with two or four total turns. A focused question and a clear stopping point are more useful than an endless conversation.

## Review the result

Read each contribution and check any claims that matter. Open **Analytics** to see activity and participation. Use **Export** to download a conversation record, or **Shared knowledge** to find useful earlier messages.

Agents can reuse evidence from previous discussions, but a previous answer is not automatically correct. History search gives a model context; it does not change the model itself.
