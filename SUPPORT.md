# Get help with DigitalRCS AgentChat

Start with the [Wiki](https://github.com/digitalrcs/AgentChat/wiki), especially [Installation](https://github.com/digitalrcs/AgentChat/wiki/Installation) and [Troubleshooting](https://github.com/digitalrcs/AgentChat/wiki/Troubleshooting). The same guides are included in the download and in the repository's `wiki/` folder.

| You need… | Where to go |
|---|---|
| Help using or installing the app | [GitHub Discussions](https://github.com/digitalrcs/AgentChat/discussions) |
| To report something broken | [Bug report](https://github.com/digitalrcs/AgentChat/issues/new?template=bug_report.yml) |
| To propose an improvement | [Feature request](https://github.com/digitalrcs/AgentChat/issues/new?template=feature_request.yml) |
| To report a security vulnerability privately | [Report a vulnerability](https://github.com/digitalrcs/AgentChat/security/advisories/new) |
| The latest version | [Releases](https://github.com/digitalrcs/AgentChat/releases/latest) |

Include the version, operating system, what you expected, and what happened. A small fictional example is usually enough. Remove private chat text, credentials, local addresses, and personal file paths from screenshots and error messages. Never attach your working database or identity files to a public report.

This is a free community project. Response times and fixes are not guaranteed. Check existing discussions and issues before starting a new one.
